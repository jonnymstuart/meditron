## Lessons
- A design component's variables (`var(--variable-ZO1Joc0jm)`) resolve in `applyChanges` only without a `pagePath`; with a page path the filter value is rejected and, worse, the index form `collectionList.filters.1.…` wipes filter 0. Set `collectionList.filters` as one JSON array string instead.
- Serialising a nested list node directly drops component-scoped filter values from the output; serialise from the component root to see the real state.
- `+Variable … scope="<collection>"` on a branch creates the field on that branch only; `collection.addItems` on main then fails with "Field not found". Create CMS fields on main with `collection.addFields`.
