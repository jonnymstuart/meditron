# Meditron AISEO

Working repository for the 5‑month SEO programme for **meditron.ch** (Framer site).
Goal: rank for *Samsung ultrasound* + the surrounding category terms in Switzerland
in four languages — **EN (primary), DE, FR, IT**.

Start with `docs/01-strategy.md`. Research that backs it: `docs/00-research-findings.md`.

## Layout

| Path | What lives here |
|---|---|
| `docs/` | Strategy, research findings, tech‑stack decisions, runbooks |
| `data/keywords/` | Keyword universe per language (CSV, source of truth for tracking) |
| `data/redirects.csv` | Legacy‑URL → new‑URL map pushed to Framer via `scripts/framer` |
| `content/{en,de,fr,it}/` | Every page/article as Markdown + front‑matter (canonical copy; Framer is the render target) |
| `reports/` | Weekly client reports (`YYYY-WW.md` + `.html`), generated by the `weekly-report` skill |
| `scripts/framer/` | Node scripts using the official `framer-api` (Server API): CMS sync, redirects, custom code, publish |
| `.claude/skills/` | Project skills Claude Code runs (see below) |
| `CLAUDE.md` | Standing context for every Claude session in this repo |

## Skills (`/skill-name`)

- `/weekly-report` – pulls Semrush position tracking + GSC, writes `reports/YYYY-WW.*`, emails the client.
- `/content-brief` – keyword‑cluster → 4‑language brief with SERP intent, headings, entities, internal links.
- `/localize` – EN master → DE/FR/IT draft localisation (Swiss variants, glossary) for the client's in-house reviewer, who sets `review: approved`.
- `/framer-sync` – pushes `content/**` into the Framer CMS, sets localisation data, publishes.
- `/redirect-audit` – diffs indexed legacy URLs against the live site, maintains `data/redirects.csv`, pushes redirects.

Third‑party skills are **vendored in this repo** (no install step): [claude‑seo](https://github.com/AgriciDaniel/claude-seo) v2.2.5 → `/seo audit|technical|hreflang|schema|content-brief|cluster|backlinks|google|plan…` (`.claude/skills/seo*`, agents in `.claude/agents/`), plus OpenClaudia's `/schema-markup` and `/serp-analyzer`, and Corey Haines' [marketingskills](https://github.com/coreyhaines31/marketingskills) v2.11.0 (50 skills: `/copywriting`, `/cro`, `/content-strategy`, `/ai-seo`, `/schema`, `/site-architecture`, `/competitors`, `/public-relations`, `/directory-submissions`, `/marketing-plan`…; its `seo-audit` is renamed `/marketing-seo-audit` to avoid clashing with claude‑seo's). Those skills read `.agents/product-marketing.md` first — keep it current. Python deps for the `/seo` scripts: `bash scripts/setup.sh`.

## One‑time setup (human)

1. Framer → project settings → **API Keys** → create key → put in `.env` as `FRAMER_API_KEY` (+ `FRAMER_PROJECT_URL`).
2. Framer → **Localization**: add `de`, `fr`, `it` locales (Pro plan, ~$20/locale/month).
3. Google Search Console: add meditron.ch (domain property), create a service account, share it, save JSON path in `.env`.
4. Semrush: create a **Position Tracking** project for meditron.ch, database `ch`, one campaign per language, import `data/keywords/*.csv`.
5. Run `bash scripts/setup.sh`.
